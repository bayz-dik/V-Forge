# V-Forge v7.1 — Focus UI + Local-First

## Perubahan utama
- Hero editor dipadatkan agar CTA proyek baru lebih cepat terlihat.
- Panel premium diubah menjadi tiga tile ringkas.
- Template Studio dipadatkan menjadi carousel horizontal.
- CTA utama disederhanakan menjadi **Proyek Baru**.
- Ditambahkan penjelasan local-first: video asli dan hasil ekspor tetap di HP.
- Cloud hanya ditujukan untuk akun, premium, metadata, preset, timeline, dan konfigurasi proyek.
- Workspace dibuat lebih rapat agar preview, timeline, dan tool lebih mudah dijangkau di HP.
- Cache PWA dinaikkan ke v7.1.0.

## Catatan storage
Versi ini tidak menambahkan upload video ke cloud. Arsitektur tetap hemat storage dan bandwidth.
