# V-Forge Motion Studio v7.0.1

## Mobile layout hotfix

- Header Studio sekarang berada dalam alur layout dan tidak lagi menimpa hero.
- Hero iklan, kartu preview, dan kartu sapaan dipisahkan secara vertikal.
- Tombol **Pilih Video & Buka Workspace** menggunakan tinggi otomatis sehingga teks tidak keluar dari card.
- Section **Proyek Terbaru** diberi jarak aman dari CTA.
- Chip template pada project card dipindah ke atas label status agar tidak bertumpuk.
- `content-visibility` pada Template Studio dinonaktifkan untuk mencegah ukuran section salah di beberapa browser Android.
- Cache Service Worker dinaikkan ke v7.0.1.
